# Security Policy

## Supported versions

Only the latest published version of the extension receives security fixes. Update through the Extensions view, or install the newest release from the GitHub Releases page.

## Reporting a vulnerability

Please do **not** report vulnerabilities in public issues.

Use GitHub's private reporting: go to the **Security** tab of this repository and choose **Report a vulnerability**.

Examples of what to report: code execution or file access beyond what the extension is meant to do, unsafe handling of workspace content or settings, leaked tokens or credentials, and weaknesses in the build or release pipeline that could ship a tampered package.

Include what you found, the extension and VS Code versions, how to reproduce it, and the potential impact. You can expect an acknowledgement within a few days and updates as the fix progresses. Once a fix is released, we will credit you if you wish.

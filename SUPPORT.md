# Support

- **Questions and ideas:** use [GitHub Discussions](../../discussions) if enabled, otherwise open an issue.
- **Bugs:** open an issue with the bug report form. Include the extension and VS Code versions, your operating system, and any errors from the **Output** panel or **Help > Toggle Developer Tools**.
- **Installation problems:** check that your VS Code version meets the requirement in the extension's listing, then try reinstalling from the Extensions view.
- **Security problems:** see [SECURITY.md](SECURITY.md).
